# Detective de mensajes: entrena tu propio filtro anti-spam

Taller de Introducción a la IA. Entrenas un clasificador **Naive Bayes** en JavaScript puro:
aprende de mensajes etiquetados, explica sus decisiones, se mide con un examen y se rompe
a propósito con datos sesgados. Sin internet, sin librerías y sin API key.

## Cómo abrirlo

Doble clic en `index.html` (Chrome o Edge). Edita en VS Code y recarga con F5.

## ¿Qué archivo uso?

| Versión | Guía | Archivo de trabajo |
|---|---|---|
| Larga (120 min, 4 TODO) | `TALLER_LARGO.md` | `modelo.js` |
| Corta (60 min, 1 TODO) | `TALLER_CORTO.md` | copia `soluciones/modelo.corto.js` sobre `modelo.js` |
| Solución (docente) | notas al final de `TALLER_LARGO.md` | `soluciones/modelo.solucion.js` |

Los datos están en `datos.js`; la página es `app.js`, `index.html` y `style.css` (no se editan).

## Requisitos

Un navegador moderno y un editor de texto (VS Code). No necesita Node.js.
